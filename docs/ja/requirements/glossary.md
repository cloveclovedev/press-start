# 用語集

この文書群で使う語の意味を決める。1つの語を1行に書く。「使わない言い方」は、同じものを指す別の言い方で、文書では使わない。

| 語 | 意味 | 使わない言い方 | 英語 |
|---|---|---|---|
| 利用者 | press-start に起こされる人。1人である | ユーザー | user |
| 予定 | Google カレンダーの1件の予定 | イベント、スケジュール | event |
| 対象の予定 | 起床時刻を決めるときに数える予定。数えない予定は `PS-ALARM-003.4` で決める | | counted event |
| 最初の予定 | その日の対象の予定のうち、最も早く始まるもの | | first event |
| アラーム設定 | 利用者が press-start に持たせる、その日に起こしてほしい時刻。「なし」もある | 目覚まし時刻 | alarm setting |
| 前倒し時間 | 最初の予定の開始の何分前に起こすか | | lead time |
| 起床時刻 | アラーム音を鳴らし始める時刻。決め方は `PS-ALARM-003` にある | アラーム時刻 | wake time |
| 起床の流れ | 起床時刻に始まり、利用者がベッドを出て二度寝を見張る時間が過ぎると終わる一連の動き。アラーム音、予定の読み上げ、スヌーズ、二度寝の見張りからなる | ルーティン、シーケンス | wake-up run |
| アラーム音 | 起床の流れの中で鳴らす音声ファイル。「アラーム音を鳴らす」のように使う | 鳴動、ベル | alarm sound |
| 予定の読み上げ | アラーム音のあとに、これからの予定と、その予定まであと何分かを日本語で読み上げること | 案内、アナウンス、ブリーフィング | briefing |
| 文面 | 予定の読み上げで読む文章 | 台本、原稿 | script |
| 定型文 | LLM を使わず、決まった型に予定を当てはめて作る文面 | | template script |
| スヌーズ | 利用者がベッドにいるあいだ、音量を上げて、アラーム音と予定の読み上げを自動で繰り返すこと。利用者がボタンを押して先延ばしするものではない | 追い込み | snooze |
| 二度寝を見張る時間 | ベッドを出たあと、ベッドに戻ったら再び鳴らすために見張る時間。過ぎたら起床の流れを終える | | back-to-bed window |
| ベッドに戻ってからの猶予 | 二度寝を見張る時間のうちにベッドに戻ってから、再び鳴らすまで待つ時間。伸びをするなど、少しベッドに戻っただけでは鳴らさないためのもの | | back-in-bed grace |
| ベッドにいる | 利用者がベッドの上にいる状態。Withings Sleep の通知で知る。眠っているかどうかは問わない | 在床、睡眠中 | in bed |
| ベッドを出た | 利用者がベッドの上にいない状態。Withings Sleep の通知で知る | 離床、起きている | out of bed |
| ベッド判定 | 利用者がベッドにいるか、ベッドを出たかを判定すること。その結果も指す | | bed state |
| 通知受信ワーカー | Withings の通知を受けて溜める、家の外に置く小さなサービス。正式には「Withings 通知受信ワーカー」 | 受付、プロキシ、webhook サーバー | relay |
| 家のサーバー | press-start が常駐し、スピーカーをつなぐ家のコンピューター | ホスト | home server |
