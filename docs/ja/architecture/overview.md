<!-- 1つのパッケージを1行に書く。「設計」には、そのパッケージを持つ設計文書へのリンクを書く。設計文書がなければ「なし」と書く。 -->

| パッケージ | 役割 | 設計 |
|---|---|---|
| `internal/core/settings` | 設定ファイル (TOML) を読み、アラーム設定、アラーム音のファイル、長さ、音量を確かめた値にする。起床時刻を決めるたびにファイルを読み直し、読めないときは最後に読めた設定を使う | なし |
| `internal/alarm` | 日付とアラーム設定から、その日の起床時刻か「起こさない日」かを決める。15秒ごとに設定を読み直して起床時刻を決め、起床時刻から1分以内に、日付ごとに1回、音量を設定してアラーム音を鳴らし、決定と開始と終了を記録する | なし |
| `internal/platform/alsa` | ALSA のミキサーの音量を `amixer` で設定し、音声ファイルを `mpv` で ALSA に直接、決めた長さだけ繰り返し鳴らす | なし |
| `cmd/press-start` | 家のサーバーの値を環境変数から読み、設定、ALSA のプレーヤー、スケジューラーを組み立てて、`SIGTERM` か `SIGINT` まで動かす。記録は JSON の行で標準出力に書く。変数が足りないか、設定を最初に読めないときは、1行を記録して終了コード1で終わる | なし |
