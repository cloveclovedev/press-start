# press-start 要求仕様書

press-start は、Google カレンダーの予定に合わせて起床時刻を決め、ベッドを出るまで起こし続ける目覚ましである。

## 解決したい課題

1. 目覚ましの時刻は、その日の予定に合わせて設定し直す必要がある。設定し忘れると、予定に間に合わない
2. 目覚ましは止めればそれで終わる。止めたあとにベッドに戻っても、もう起こしてくれない
3. 目覚ましは音で起こすだけで、なぜ今起きないといけないのかを伝えない。意識がはっきりしないまま止めて、二度寝してしまう

## 目的

予定から起床時刻を決め、起きる理由を伝え、ベッドを出たことを確かめるまで起こし続けることで、朝の予定に間に合うようにする。

## 指標

- 鳴るべき朝に鳴らなかった回数。目標は0回
- 最初の予定の開始より後にベッドを出た朝の回数。目標は0回
- 起床時刻からベッドを出るまでの時間

## 登場人物

- 利用者: 起こされる人。アラーム設定を決める
- Google カレンダー: 予定を持つ。press-start は読むだけである
- Withings Sleep: ベッドに敷くセンサー。ベッドにいるか、ベッドを出たかを知らせる
- LLM: 予定の読み上げの文面を作る

## 範囲外

- 睡眠の状態に合わせて起床時刻を変えること
- 複数の利用者

## フェーズ

- v0.1: 予定とアラーム設定から起床時刻を決め、アラーム音を鳴らし、定型文で予定の読み上げをする
- v0.2: ベッド判定を受け取り、ベッドにいるあいだスヌーズを繰り返す
- v0.3: 予定の読み上げの文面を LLM で作る
