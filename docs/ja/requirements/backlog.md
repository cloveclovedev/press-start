# バックログ

今のバージョンには入れないと決めたが、あとで要件に取り入れたいことを書き留める。着手すると決めた項目は、要件のページに書いて、ここから消す。

項目ごとに、内容、後回しにした理由、見直すきっかけを書く。

### YouTube Music の曲をアラーム音にする

アラーム音として、音声ファイルの代わりに YouTube Music の曲やプレイリストを鳴らす。

- 後回しにした理由: YouTube Music には公式の API がない。使える方法 (例: Music Assistant) は、有料のアカウント、ブラウザーの cookie での認証、定期的な認証のやり直しが必要で、毎朝確実に鳴らすという目的に合わない
- 見直すきっかけ: v0.3 まで動き、音声ファイルのアラーム音に飽きたとき

---

### 挨拶とラジオ体操

起床の流れに、最初の挨拶と、予定の読み上げのあとのラジオ体操の音声を足す。

- 後回しにした理由: 起こすことに直接つながらない。起床の流れの基本が固まってから足しても、要件の形は変わらない
- 見直すきっかけ: v0.2 のスヌーズが毎朝動くようになったとき

---

### 外からの見張り

起床時刻に起床の流れが始まらなかったことを、家の外から気付けるようにする。

- 後回しにした理由: v0.1 では、鳴らなかった朝は利用者自身が気付く。見張りを足すほどの必要がまだない
- 見直すきっかけ: 鳴らなかった朝が1回でも起きたとき
