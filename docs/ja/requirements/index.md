# 要求と要件

press-start の要求と要件の文書の入口である。

## 全体

- [要求仕様書](overview.md): 解決したい課題、目的、指標、登場人物、範囲外、フェーズ
- [技術要素](technology.md): 使う技術と、選んだ理由
- [用語集](glossary.md): 語の意味と、使わない言い方
- [バックログ](backlog.md): 今のバージョンには入れないが、あとで取り入れたいこと
- [ソースコード全体構成](../architecture/overview.md): パッケージと、その役割と設計

## カテゴリごとの要件

IDの接頭辞は `PS` である。カテゴリごとにディレクトリを分け、要件のページ (`index.md`) と図を置く。

| カテゴリ | ページ | 内容 |
|---|---|---|
| `ALARM` | [起床時刻とアラーム音](alarm/index.md) | アラーム設定、起床時刻の決め方、アラーム音、スヌーズ、起床の流れの続け方 |
| `BRIEF` | [予定の読み上げ](brief/index.md) | 予定の読み上げで伝えること、文面の作り方、音声にする方法 |
| `BED` | [ベッド判定](bed/index.md) | Withings Sleep の通知の受け取り方と、寝ている判定と起きている判定の決め方 |
| `DEPLOY` | [家のサーバーで動かす](deploy/index.md) | press-start を家のサーバーに配り、動かし続けること。家のサーバーごとの値と秘密の値の渡し方 |
