# 用語集

この文書群で使う語の意味を決める。1つの語を1行に書く。「使わない言い方」は、同じものを指す別の言い方で、文書では使わない。

| 語 | 意味 | 使わない言い方 | 英語 |
|---|---|---|---|
| 利用者 | press-start に起こされる人。1人である | ユーザー | user |
| 予定 | Google カレンダーの1件の予定 | イベント、スケジュール | event |
| 対象の予定 | 起床時刻を決めるときに数える予定。数えない予定は `PS-ALARM-003.4` で決める | | counted event |
| 最初の予定 | その日の対象の予定のうち、最も早く始まるもの | | first event |
| アラーム設定 | 利用者が press-start に持たせる、その日に起こしてほしい時刻。「なし」もある | 目覚まし時刻 | alarm setting |
| 前倒し時間 | 最初の予定の開始の何分前に起こすか | | lead time |
| 起床時刻 | 鳴動を始める時刻。決め方は `PS-ALARM-003` にある | アラーム時刻 | wake time |
| 起床の流れ | 起床時刻に始まり、離床で終わる一連の動き。鳴動、案内、追い込みからなる | ルーティン、シーケンス | wake-up run |
| 鳴動 | 起床の流れの中で、音声ファイルを鳴らすこと | アラーム音、ベル | ringing |
| 案内 | 鳴動の直後に、これからの予定と起きる理由を日本語で読み上げること | アナウンス、ブリーフィング | briefing |
| 文面 | 案内で読み上げる文章 | 台本、原稿 | script |
| 定型文 | LLM を使わず、決まった型に予定を当てはめて作る文面 | | template script |
| 追い込み | 在床が続くあいだ、音量を上げて鳴動と案内を繰り返すこと | スヌーズ | escalation |
| 在床 | 利用者がベッドの上にいる状態。Withings Sleep の通知で知る | 寝ている、睡眠中 | in bed |
| 離床 | 利用者がベッドを出た状態。Withings Sleep の通知で知る | 起きている | out of bed |
| 受付 | Withings の通知を受けて溜める、家の外に置く小さなサービス | プロキシ、webhook サーバー | relay |
| 家のサーバー | press-start が常駐し、スピーカーをつなぐ家のコンピューター | ホスト | home server |
